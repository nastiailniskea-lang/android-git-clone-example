# Название Проекта

Краткое описание проекта (например: Приложение для списка задач в рамках 6 спринта).

## 🛠 Технические детали

| Параметр | Значение |
| :--- | :--- |
| **Android Studio** | Вставьте версию (например, 2023.1.1) |
| **Язык** | Kotlin |
| **JDK** | Вставьте версию (например, 17) |
| **minSdk** | Вставьте число (например, 24) |
| **targetSdk** | Вставьте число (например, 34) |

## 🚀 Как запустить проект

1.  **Склонируйте репозиторий:**
    ```bash
    git clone <ссылка-на-ваш-репозиторий>
    ```
2.  **Откройте проект:**
    *   Запустите Android Studio.
    *   Выберите **Open** и укажите папку с проектом.
3.  **Синхронизируйте Gradle:**
    *   Дождитесь окончания синхронизации.
4.  **Запустите приложение:**
    *   Нажмите кнопку **Run** (зеленый треугольник) или `Shift + F10`.
